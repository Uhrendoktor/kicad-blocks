## Native KiCad, GUI, and evidence runners

These scripts require KiCad, a real IPC server, a GUI session, or rendered evidence. They use the `acceptance_*.py` prefix (or a descriptive non-test filename), so pytest does not mistake an executable acceptance runner for a test module that collects zero tests.

| Runner | Purpose | CI invocation / dependency |
| --- | --- | --- |
| [`tests/acceptance_eeschema_gui.py`](../../tests/acceptance_eeschema_gui.py) | Starts the real Eeschema editor under a virtual display, creates a block, and verifies that the editor can save it. | .github/workflows/ci.yml — Verify Eeschema GUI editor launch and save |
| [`tests/acceptance_instance_configuration_gui.py`](../../tests/acceptance_instance_configuration_gui.py) | Drives the real Tk instance-configuration dialog and verifies profile-selected variant, typed parameter, PCB layout, and update/transaction calls through a mocked schematic/IPC collaborator. | Called by acceptance_plugin_registration.py and capture_visual_docs.py |
| [`tests/acceptance_ipc_headless.py`](../../tests/acceptance_ipc_headless.py) | Starts KiCad headlessly and verifies schematic IPC placement, facade configuration, and project-local implementation behavior. | .github/workflows/ci.yml — Verify real KiCad IPC placement (headless) |
| [`tests/acceptance_library_picker_gui.py`](../../tests/acceptance_library_picker_gui.py) | Exercises the searchable native block picker with real Tk widgets and X11 keyboard events. | .github/workflows/ci.yml — Verify native-rendered functional block picker |

## Inventory rules

- Every `tests/test_*.py` module must contain at least one discoverable `test_*` function or method.
- A test method name must be unique within its class. Duplicate method definitions are rejected because Python silently shadows the earlier one.
- Every standalone `tests/acceptance_*.py` runner is listed above.
- The CI `--check` mode compares this file with the current source tree and fails when a test, purpose, source line, or runner entry is missing or stale.
