# How-to guides

These guides start from a specific goal and describe the steps to reach it. They assume you understand the basic facade/implementation model; for a first-use sequence, follow the [first-block tutorial](tutorials/first-block.md).

## Create and use blocks

- [Create, find, and place blocks](how-to/create-and-place.md) — extract a hierarchical sheet, inspect the facade, search libraries, and use the native symbol chooser.
- [Configure an instance](how-to/configure.md) — choose profiles, implementation variants, parameters, and PCB layouts for one placed symbol.

## Maintain a library

- [Edit, publish, and synchronize implementations](how-to/publish-and-sync.md) — update a shared block, edit facade artwork, create project-local copies, and resolve sync conflicts.
- [Nest blocks and validate libraries](how-to/nesting-and-validation.md) — compose dependencies, validate all registered libraries, and export recursive BOM/ERC results.

## Reuse PCB layouts

- [Manage and apply PCB layouts](how-to/pcb-layouts.md) — add blank or existing boards, link them to implementations, merge layouts into a separate project-board copy, and position imported groups.

## Exact behavior

Use the [feature reference](reference.md) for exact action names, stored files, field names, parameter semantics, and technical limits.
