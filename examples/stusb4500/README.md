# STUSB4500 USB-PD sink reference block

This example uses the real **STUSB4500QTR** USB Type-C / USB Power Delivery
sink controller from STMicroelectronics. The editable KiCad schematic is
generated by `generate_reference.py` from the installed KiCad symbol
libraries, with the ESDA25W three-terminal protection array defined locally.

## Source design

The component placement and circuit sections follow **ST DS12499 Rev. 8,
Figure 10, “Typical schematic with MCU” (datasheet page 26/42)**. The external
configuration examples follow **Table 19**:

| Profile | PDO | Current |
|---|---:|---:|
| PDO1 | 5 V | 2.40 A |
| PDO2 | 9 V | 1.33 A |
| PDO3 | 12 V | 1.00 A |

The schematic groups the design in the same signal-flow order as the ST
reference: USB Type-C receptacle and CC protection on the left, STUSB4500 and
its decoupling/address network in the center, the protected VBUS sink power
path across the upper-right, and the optional MCU/I²C interface on the right.

## Reproduce

With KiCad CLI and its standard symbol libraries installed. The visual-documentation workflow pins the official KiCad 10.0.5 symbol-library release in [kicad-symbols.lock](kicad-symbols.lock) so CI uses a reproducible set of real component symbols:

```bash
python examples/stusb4500/generate_reference.py
```

The generator function is also used by the visual-documentation CI capture.
CI exports the generated schematic with `kicad-cli sch export svg` and stores
the editable `.kicad_sch` alongside the SVG preview.

## Symbol attribution

The standard component symbols embedded in the generated schematic are sourced
from the official [KiCad symbol library repository](https://gitlab.com/kicad/libraries/kicad-symbols),
pinned to the 10.0.5 release in `kicad-symbols.lock`. KiCad library symbols
are distributed under the repository's CC BY-SA 4.0 licensing terms. The
ESDA25W three-pin symbol is a local pinout-accurate representation based on
ST's component datasheet.

## Important design note

This is a **datasheet-derived reference reconstruction**, not a production
design or a claim of electrical-rule-check sign-off. ST describes its
application schematics as generic starting points and places final system
implementation and validation on the designer. Before manufacturing, verify
the exact pin-to-net wiring, protection ratings, component footprints,
thermal/current capability, USB Type-C/PD compliance, and the selected NVM
PDO configuration against the current datasheet and the target application.

**Primary source:** [STUSB4500 datasheet DS12499, Rev. 8](https://www.st.com/resource/en/datasheet/stusb4500.pdf), Figure 10 and Table 19.
